## 技术实现

### 涉及的文件

| 文件 | 改动内容 |
|------|----------|
| `sdone/src/canvas/ParticleEngine.ts` | **新建** — 粒子数据模型 + 核心引擎（生成/推进/移除） |
| `sdone/src/canvas/SceneRenderer.ts` | 新增 `onPreFrame` hook、`particleStateProvider`、`drawParticles()` 渲染方法；移除未使用的 import |
| `sdone/src/main.ts` | 在 `main.ts` 中实例化 `ParticleEngine`，在 render loop 前调用 `update()`，连接 `onResetCallbacks` 触发 `reset()` |
| `sdone/src/canvas/index.ts` | 导出 `ParticleEngine` 和 `ParticleState` 类型 |

### 架构设计

```
ParticleEngine（独立模块，无 GraphState 依赖）
  ├── update(dt, connections, nodes, simState) → ParticleState
  ├── getState() → ParticleState（只读，供渲染）
  └── reset() → void（AC6）

SceneRenderer
  ├── onPreFrame: ((dt) => void) | null   ← main.ts 在此调用 engine.update()
  └── particleStateProvider: () => ParticleState | null  ← drawParticles() 消费
```

- **数据模型（Particle）：** `{ t: number; speed: number; alpha: number; age: number }`
- **最大粒子数：** `ceil(rate * 0.5)`
- **速度映射：** `rate * 0.1` normalized-units/秒（rate=10 → ~1s 全程遍历）
- **淡入：** `alpha = min(1.0, age / 0.3)`（前 0.3s 淡入）
- **暂停时：** 不移除粒子，仅冻结 `t` 和 `age` 推进
- **零速率连接：** 移除所有粒子（AC3）

### 依赖项

- `Connection.rate`（GraphState，已存在）
- `SimulationState`（`running` | `paused` | `idle`，Story 4.1 已存在）

## 边缘情况

| 场景 | 预期行为 |
|------|----------|
| 删除连接 | 对应粒子立即清理，`particlesByConnection` 中移除此连接条目 |
| 连接速率变为 0 | 粒子被清除，`spawnTimers` 重置 |
| 连接速率从 0 变为正值 | 重新开始生成粒子 |
| 长时间后台挂起 | `dt` 被 clamp 在 0.1s，避免粒子跳跃 |
| 无节点或无连接的空图 | `particlesByConnection` 为空 Map，渲染跳过 |
| RESET 后立即运行 | 粒子从零重新生成，无残留状态 |
