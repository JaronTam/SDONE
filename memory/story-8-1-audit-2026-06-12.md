### Key Design Decisions

1. **`updateModuleSize` no-op comparison uses direct `===`** — `undefined !== number` is always true, so first-set always triggers version bump (per B1 audit fix)
2. **`updateModuleLabel` whitespace handling** — only `.trim() === ''` triggers fallback; leading/trailing whitespace on non-empty strings is preserved
3. **Min clamp constants** are private to `mutations.ts` (`MIN_MODULE_WIDTH = 60`, `MIN_MODULE_HEIGHT = 40`), not exported — consumers use `DEFAULT_MODULE_*` for rendering defaults
4. **`DEFAULT_LABEL` map** is private to `mutations.ts` — maps `ModuleType` to default names ('Source'/'Stock'/'Sink')
